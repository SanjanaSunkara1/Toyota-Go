name: Toyota Go product scope
description: User-defined branding, layout preservation and illustrative comparison constraints.
---

The user requested the name **Toyota Go**, exact tagline **To You Total Assistance**, actual Toyota logo, and a red header with white text inspired by the supplied SeedBank reference. Keep the supplied Toyota building photo on the Home account panel and use their supplied SUV trail photo in place of the illustration on the post-quiz results page.

**Why:** The user explicitly requested these branding and scope constraints.

**How to apply:** Keep these names and references consistent in future UI changes. The SeedBank reference indicates the header treatment, not permission to replace the existing app with a different framework. The user subsequently requested red accents for “matches,” comparison/drive actions, Deal Benefit Score, “Your decision in perspective,” annual-value table headings, “sustainability,” and IIHS vehicle names.

The user wants up to three questions in each quiz card before Next, a Skip option for every question, and a three-line menu with Home, Customization, and Vehicle Safety & Sustainability. Loan questions apply to current owners with loans; lease questions apply to current lessees. After the quiz, use familiar dropdown filters rather than sending customers back through “Adjust my answers.” Show all matching Toyota models rather than a fixed six-car shortlist. Home should include their supplied original dealership-financing photo.

**Why:** The user explicitly revised the one-at-a-time flow to three-question cards, asked for easier results filtering, and objected to repeatedly seeing the same six cars.

**How to apply:** Preserve progressive, skippable questioning. Missing contract data must remain unknown, never be replaced with sample amounts presented as a customer's actual details.

The user chose **clearly labeled illustrative estimates** for deal, resale, safety, ecological and reliability comparisons.

**Why:** Verified model-year/trim-level data was not supplied, and the user selected estimates when asked.

**How to apply:** Clearly distinguish assumed feature coverage from crash protection, maintenance budgets from measured reliability, and modeled retained value from guaranteed resale or financial gain. Never imply illustrative Toyota/rival differences are verified brand performance.

The user's request to compare **real insurance plans** is separate from the earlier permission to use illustrative vehicle metrics.

**Why:** The user explicitly requested real insurance comparisons and a prompt after vehicle selection.

**How to apply:** Never invent insurer premiums or present sample rates as live quotes. Use actual customer-supplied offers or an authorized quote-provider connection, clearly distinguishing unverified entered quotes from provider-returned rates and binding policies.
