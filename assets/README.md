# Brand asset

VIS_toyota_logo_horiz_black_RGB_2023.svg, retrieved from the Toyota website:

https://delivery.tcom.assetscs.toyota.com/adobe/assets/urn:aaid:aem:caee6520-2e75-4408-b632-247c747a3e53/as/VIS_toyota_logo_horiz_black_RGB_2023.svg
